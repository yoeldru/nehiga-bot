# 🚗 בוט נהיגה

אפליקציית אנדרואיד שעונה אוטומטית להודעות ווטסאפ כשאתה בנהיגה.

- **הפעלה ידנית:** כפתור "מצב נהיגה" בווילון ההתראות, או המתג באפליקציה.
- **הפעלה אוטומטית:** כשהטלפון מתחבר ל-Bluetooth של הרכב, ונכבה כשהוא מתנתק.
- כל אדם מקבל תשובה **פעם אחת בכל נסיעה**, גם אם שלח כמה הודעות.
- כברירת מחדל לא עונה בקבוצות (אפשר לשנות במתג).
- כשהמצב פעיל מופיעה התראה קבועה עם כפתור "כבה".
- **כיבוי ידני גם כשהופעל מהרכב** (עצירה ארוכה): המצב נשאר כבוי עד החיבור הבא לרכב.
- **יומן פעולות** רושם כל הפעלה וכיבוי ומה גרם להם, חיבור וניתוק מהרכב, למי נשלחה תשובה (שם ומספר), דילוגים על קבוצות, שינויי הגדרות ושגיאות. אפשר לנקות אותו ידנית או לבחור ניקוי אוטומטי: שבוע, חודש, 3 חודשים או אף פעם.

---

## שלב 1: העלאה ל-GitHub (פעם אחת, מהמחשב)

1. היכנס ל-[github.com](https://github.com) (אם אין לך חשבון, צריך לפתוח).
2. לחץ **New repository**, תן שם `nehiga-bot`, בחר **Private** ולחץ **Create repository**.
3. בדף שנפתח לחץ על הקישור **uploading an existing file**.
4. חלץ את קובץ ה-ZIP במחשב, ו**גרור את כל התוכן שבתוך התיקייה `driving-bot`** לחלון (כולל התיקייה `.github` ו-`app`).
5. לחץ **Commit changes**.

## שלב 2: הבנייה (אוטומטית)

1. עבור ללשונית **Actions**. תראה בנייה רצה, והיא לוקחת כ-4 עד 5 דקות.
2. כשמופיע ✅ ירוק, עבור לדף הראשי של הפרויקט ולחץ בצד על **Releases**.
3. משם אפשר להוריד את `nehiga.apk`, הכי נוח ישירות מהטלפון (מחובר לאותו חשבון GitHub).

> כל שינוי שתעלה בעתיד ייבנה מחדש אוטומטית, והגרסה החדשה תותקן מעל הקודמת בלי לאבד הגדרות.

## שלב 3: התקנה בטלפון

1. פתח את `nehiga.apk` שהורדת. אם נשאלת, אשר "התקנה ממקורות לא ידועים" לדפדפן או ל"הקבצים שלי".
2. אם Play Protect מזהיר, בחר **פרטים נוספים ← התקן בכל זאת**. זה רגיל לאפליקציה שלא הגיעה מהחנות.

## שלב 4: הגדרה באפליקציה

1. אשר את ההרשאות שהיא מבקשת בפתיחה (התראות ומכשירים בקרבת מקום).
2. **תן גישה להתראות:** הדלק את "בוט נהיגה" ברשימה.
   - **אם המתג אפור ולא ניתן ללחיצה** (אנדרואיד חוסם את זה לאפליקציות שלא מהחנות): חזור לאפליקציה, לחץ **"המתג אפור? פתח פרטי אפליקציה"**, ואז ⋮ למעלה ← **"אפשר הגדרות מוגבלות"**. אחרי זה חזור ונסה שוב.
3. **אל תגביל סוללה לבוט:** אשר. בלי זה סמסונג עלולה להרדים את הבוט.
4. **בחר את ה-Bluetooth של הרכב** מהרשימה (הקורולה תופיע בשם שהיא מופיעה אצלך ב-Bluetooth).
5. הוסף לווילון: משוך את הווילון למטה, לחץ על העיפרון, וגרור את **"מצב נהיגה"** פנימה.

## בדיקה

הדלק את מצב הנהיגה, ובקש ממישהו לשלוח לך הודעה בווטסאפ. הוא אמור לקבל את התשובה תוך שנייה, ובאפליקציה יופיע שמו תחת "נענו בנסיעה הזו".

## אם זה לא עובד

- **אין תשובה בכלל:** בדוק שבאפליקציה מופיע "✅ גישה להתראות" ושהסוללה לא מוגבלת. בנוסף, ההתראות של ווטסאפ חייבות להיות מופעלות. אם השיחה פתוחה על המסך, אין התראה ולכן גם אין תשובה.
- **לא נדלק אוטומטית ברכב:** ודא שנבחר רכב ושאישרת את הרשאת "מכשירים בקרבת מקום".

## מבנה הקוד

| קובץ | מה הוא עושה |
|---|---|
| `ReplyListenerService.kt` | הבוט: מקבל כל התראה, ואם היא מווטסאפ "לוחץ" על כפתור ההשב ושולח את ההודעה |
| `DrivingMode.kt` | הדלקה וכיבוי של המצב, וההתראה הקבועה |
| `DrivingTileService.kt` | הכפתור בווילון |
| `Receivers.kt` | זיהוי חיבור וניתוק מהרכב, וכפתור "כבה" |
| `MainActivity.kt` + `activity_main.xml` | מסך ההגדרות |
| `Prefs.kt` | שמירת ההגדרות |
| `EventLog.kt` | היומן: כתיבה, קריאה וניקוי |
| `LogActivity.kt` + `activity_log.xml` | מסך היומן |
| `.github/workflows/build.yml` | הבנייה האוטומטית ב-GitHub |
